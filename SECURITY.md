# Security Policy - MediaForge

This document outlines reporting pathways and security updates procedures.

---

## 🔒 Supported Versions

Vulnerability patches are backported to the current active release branches:

| Version | Supported |
| :--- | :--- |
| **0.1.x** | 🟢 Yes (Active Release Candidate) |
| **< 0.1.0** | 🔴 No |

---

## 🛑 Reporting a Vulnerability

If you identify a security issue:
1. Do NOT file public issues on GitHub.
2. Email security findings privately to `security@mediaforge.local` or contact core maintainers directly.
3. Provide a clear description, reproduction scripts, and sandbox conditions to assist replication efforts.

---

## 🛡️ Response Lifecycle
- Maintainers will verify the vulnerability report within 24 hours.
- We will publish hotfixes and release tags to the repository immediately upon stabilization.
